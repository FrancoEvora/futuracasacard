# Futura Casa — Cardápio Imobiliário v6.4 Organizado

Esta versão mantém a experiência visual da versão anterior, mas separa os arquivos para produção.

## Estrutura

```text
index.html
assets/
  css/
    styles.css
  js/
    app.js
  img/
    imagens extraídas do HTML original
```

## Publicação no GitHub/Vercel

Suba todos os arquivos e pastas na raiz do projeto.

A raiz precisa ficar assim:

```text
index.html
assets/
```

Não suba apenas o `index.html`, pois ele depende de `assets/css`, `assets/js` e `assets/img`.

## Qualidade das imagens

As imagens foram extraídas do base64 original sem recompressão. Ou seja, não houve redução de qualidade; apenas mudança de localização dos arquivos.
